# Desafio Técnico - Automação com Cypress | Nexdom

Este projeto é parte de um desafio técnico que tem como objetivo validar conhecimentos em automação de testes end-to-end utilizando o Cypress.  
A aplicação testada foi o site oficial da empresa [Nexdom](https://nexdom.tec.br).

---

## Descrição do Projeto

Automatização de testes E2E no site da Nexdom para garantir que elementos essenciais da página estejam funcionando corretamente.  
O projeto foi desenvolvido com **Cypress** e **Cucumber (Gherkin)** para garantir legibilidade e organização dos testes.  
Além dos testes de interface, o projeto incluirá testes de API utilizando a **GitHub REST API**.

---

## Tecnologias Utilizadas

- [Node.js](https://nodejs.org/)
- [Cypress](https://www.cypress.io/)
- [Cucumber / Gherkin](https://github.com/badeball/cypress-cucumber-preprocessor)
- [GitHub REST API](https://docs.github.com/en/rest)
- VSCode
