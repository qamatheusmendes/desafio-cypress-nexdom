# Desafio Técnico — Automação com Cypress | Nexdom

Este projeto foi desenvolvido como parte do desafio técnico da Nexdom, com foco em testes automatizados E2E e testes de API.

---

## 🧪 O que foi testado

- Elementos essenciais do site oficial da [Nexdom](https://nexdom.tec.br)
- Validação de funcionalidades com Cypress
- Escrita de cenários com Cucumber (Gherkin)
- Testes de API utilizando a GitHub REST API

---

## 🚀 Tecnologias utilizadas

- Node.js
- Cypress
- Cucumber / Gherkin
- GitHub REST API
- VSCode
